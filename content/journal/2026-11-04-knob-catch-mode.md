## Question
How can I move a control knob without the value changing, for example the resonance on Super Filter?

## Key takeaways
- SYSTEM > GENERAL > EFX Knob Mode "Catch": the value changes only once the knob reaches the current value. ([SYSTEM](https://static.roland.com/manuals/sp-404mk2_reference_v550/en-US/7964634778545547.html))
- EFX Knob Mode "Direct" jumps to the knob position; "Manual" outputs the knob positions when you switch effects. ([SYSTEM](https://static.roland.com/manuals/sp-404mk2_reference_v550/en-US/7964634778545547.html))
- Edit Knob Mode (Catch or Direct) does the same for the editing screens such as PITCH/SPEED; DJ mode always uses Catch. ([SYSTEM](https://static.roland.com/manuals/sp-404mk2_reference_v550/en-US/7964634778545547.html))
- To get there: `[SHIFT]` + pad `[13]`, SYSTEM, `[CTRL 3]` to the GENERAL tab, then select and set with `[VALUE]`. ([Editing the settings related to this unit (System)](https://static.roland.com/manuals/sp-404mk2_reference_v550/en-US/7952346778529419.html))

## Details
With Catch, if RESONANCE is at 40 and the knob sits at 80, sweep the knob down
to 40 and it takes over from there. EFX Knob Mode covers the effects (BUS FX);
Edit Knob Mode covers the sample editing screens.
