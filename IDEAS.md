# Ideas for later

Extras for the knowledge site (see `SITE-PLAN.md`) that are parked until the
first version works. Pick one, move it into the plan, build it.

- **"Still to try" board**: collect the "open questions" sections from all
  entries on one page; checking one off moves it to the journal as verified.
- **Verified-on-unit badges**: the `status` field exists so that, once I
  confirm something on the hardware, Claude flips `manual` to `verified`. A
  counter on the knowledge index ("68 facts, 21 verified") makes progress
  visible.
- **Flashcards / quiz mode** for shortcuts: random prompt ("How do you enter
  the Format SD card screen?"), reveal answer. Built from the same bullets.
- **Glossary** page: BUS FX, MFX, Skip Back, DJ mode, Chop, Resample, with a
  one-liner each and a link to the manual section.
- **Session log** page: one row per Claude Code session with date, entries
  produced, and the session id, so I can trace any fact to its conversation.
- **Firmware tracking**: entries carry `firmware`; when I update the unit,
  the site can flag facts learned on an older version.
- **Recipes / workflows** topic: multi-step things I actually do (chop a
  Bandcamp track into a bank, resample a loop with effects), distinct from
  single facts.
- **Gear and sources** page: where the sample packs came from, what is on the
  card, so SD-card sessions have context.
